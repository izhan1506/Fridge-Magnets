## A note on the OAuth docs

`setup/oauth/` holds seven files covering the same procedure at different levels of
detail (`START_HERE`, `QUICK_START`, `SETUP`, `STEP_BY_STEP`, `VISUAL_GUIDE`,
`WHAT_YOU_LL_SEE`, plus a `README`). They were written separately and overlap
heavily. Worth collapsing into one document with sections.
